CHAMFER UI

Um design system de interface militar-futurista: cantos cortados, linhas finas, vermelho como cor de sistema e ciano como destaque. CSS puro, componentes por classe, como o shadcn, prontos para qualquer stack.

Instalar

São dois arquivos. O CSS traz tokens, a primitiva de chanfro e todos os componentes. O JS (opcional, 3 KB) liga abas, dialog, stepper, slider e toast por data-attributes. Coloque a classe cf-root no <body> ou no contêiner da aplicação.

<link rel="stylesheet" href="chamfer.css">
<script src="chamfer.js" defer></script>

<body class="cf-root cf-screen">
  <button class="cf-btn">Conectar</button>
</body>

Geometria

Nada é arredondado. Cada canto é reto ou cortado a 45°. A célula padrão corta o canto inferior-direito; painéis grandes cortam dois cantos opostos.

.cf-cut-br · padrão
.cf-cut-diag · painel
.cf-cut-tl
.cf-cut-anti
.cf-cut-all
.cf-cut-xl · 32px
Bracket + gapperNovo 680Módulo
  1. 1Bracket. Barra de 3px à esquerda. Carrega raridade, status ou seleção.
  2. 2Gapper. Fresta de 3px entre bracket e corpo. Impede o fundo de "vazar" e dá leitura de peça encaixada.
  3. 3Célula. Linha de 1px + fundo, ambos recortados pelo mesmo polígono. O chanfro interno é recalculado para a linha ter espessura constante na diagonal.
  4. 4Notch. Entalhe na borda (.cf-notch), detalhe de usinagem.
/* Qualquer elemento vira chanfrado: */
<div class="cf-frame cf-cut-diag cf-cut-lg">…</div>

/* Ou controle canto a canto: */
.meu-painel { --cf-tl: 16px; --cf-br: 16px; --cf-tr: 0px; --cf-bl: 0px;
              --cf-line: var(--cf-red); --cf-fill: rgb(25 23 34 / .9); }

Estados

Quatro estados com opacidades fixas. A linha acende no hover, o fundo ganha um tom de ciano; selecionado preenche em vermelho a 40%; o clique dá um flash a 70%.

Idle
linha 30% · fundo 95%
Hover
linha 100% · ciano 10%
Selecionado
linha 100% · vermelho 40%
Click · flash
linha 100% · vermelho 70%

Em qualquer .cf-frame, adicione .cf-interactive para ganhar os quatro estados. Seleção vem de aria-selected, aria-pressed ou .is-active.

Usando no Angular

O CSS é global e as classes funcionam direto nos templates. Um wrapper fino dá a ergonomia de componente.

// angular.json → projects.app.architect.build.options
"styles": ["src/styles.scss", "src/chamfer/chamfer.css"],
"scripts": ["src/chamfer/chamfer.js"]

// cf-button.component.ts
@Component({
  selector: 'cf-button',
  standalone: true,
  template: `<button class="cf-btn" [class]="'cf-btn--' + variant + ' cf-btn--' + size"
                     [disabled]="disabled"><ng-content /></button>`,
})
export class CfButton {
  @Input() variant: 'default' | 'solid' | 'cyan' | 'gold' | 'ghost' = 'default';
  @Input() size: 'sm' | 'md' | 'lg' = 'md';
  @Input() disabled = false;
}

// Para abas, dialog e stepper renderizados depois do boot:
ngAfterViewInit() { (window as any).ChamferUI?.init(this.el.nativeElement); }
